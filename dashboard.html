How to run a fair comparison

  1. Use the same saved/public listing scenarios for every method.
  2. Assign ground truth before analysing results.
  3. Record text-only, metadata-only and multi-signal scores from one scan.
  4. Run the backend and repeat uncertain/elevated cases for the full-workflow comparison.
  5. Alternate score-only and explanation conditions across evaluators.
